# VidatronArchive

Archive of source code from **Vidatron** - an AI-powered healthy lifestyle companion robot built as a software engineering capstone project (Western University, 2025–2026).

## Important notice

**This repository is for reference and archival purposes only.** It is **not intended to be cloned and run as a standalone application.**

The code here reflects the Vidatron project as developed for a Raspberry Pi 5–based robot with custom hardware (touchscreen, motors, ultrasonic sensors, UPS HAT, 3D-printed chassis, etc.). Running it requires:

- Specific hardware and wiring not included in this repo
- OS-level configuration (Ubuntu Server, boot setup, user accounts)
- Environment setup, dependencies, and credentials not documented here
- Integration with physical subsystems (movement, sensors, UI on device)

Some paths, configs, or assets may be incomplete, environment-specific, or omitted for privacy and portability.

## What this repo contains

A snapshot of the Vidatron codebase, including modules for:

- Main application logic
- Movement / motor control
- Touchscreen UI (Kivy)
- AI and smart UI components
- Supporting scripts
